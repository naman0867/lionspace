# 🚀 LionSpace

LionSpace is a full-stack productivity and collaboration platform built using the MERN stack.  
It includes authentication, task management, AI features, and real-time capabilities.

---

# 🌟 Features

- 🔐 User Authentication (JWT)
- ✅ Task Management System
- 🤖 AI-powered Routes
- ⚡ Real-time Communication using Socket.IO
- 📦 REST API Architecture
- 🌐 Full-stack Deployment Ready
- 🎨 Modern UI with Tailwind CSS
- 📱 Responsive Design

---

# 🛠️ Tech Stack

## Frontend
- React.js
- Vite
- Tailwind CSS
- Axios
- React Router DOM

## Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Socket.IO
